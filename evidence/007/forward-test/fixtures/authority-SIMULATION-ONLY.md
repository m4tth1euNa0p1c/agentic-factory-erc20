# FIXTURE SYNTHÉTIQUE — référence sans autorité effective

Cette chaîne remplit le champ structurel authorityRef dans des documents fictifs afin de tester le CLI. Elle ne constitue ni une autorisation d’un responsable, ni une autorisation de dépense, ni une permission de lancement. effectiveAuthorization=false. Le plan opérationnel doit demeurer DRAFT. Les plafonds sont uniquement ceux du scénario fourni.

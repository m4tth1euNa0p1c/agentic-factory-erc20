# Test d’utilisabilité avec FIXTURES SYNTHÉTIQUES

Tous les dossiers d’expérience et leurs preuves décrivent des données fictives. Aucun script de préparation de sandbox n’a été exécuté, aucun fichier utilisateur manipulé, aucun réseau appelé ni aucune dépense engagée par ce test. Les sorties du CLI sont des observations réelles de son comportement sur ces fixtures; elles ne démontrent aucun gain opérationnel réel.

Le protocole opérationnel reste DRAFT avec authorityRef=null. Les trois plans READY servent uniquement à simuler les branches alternatives A, B et C, chacune avec son budget cumulé fictif. Ils ne représentent pas trois essais successifs et ne créent aucune autorisation réelle. La référence d’autorité de simulation n’autorise aucune dépense.

Les SHA de plan, configuration et preuves sont des empreintes réelles de fichiers fictifs. Le commitSha du produit est une identité fictive explicitement décrite dans fixtures/NOTICE.json; aucun code produit n’a été testé.

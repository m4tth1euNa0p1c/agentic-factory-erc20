## 2. Points de sécurité relevés (impactent la conception)

1. **Besu RPC** : exposer uniquement `ETH,NET,WEB3,TXPOOL` sur le réseau Docker interne ; jamais `ADMIN`/`DEBUG` ; `--host-allowlist` restreint ; ports publiés sur `127.0.0.1` uniquement. La doc Besu rappelle que `0.0.0.0` expose le nœud : on le limite au réseau Docker.
2. **Web3Signer** : seul composant à détenir les clés. Accessible uniquement par l'adaptateur (réseau `signing` dédié). Clés chiffrées (`file-keystore`), mots de passe dans `infra/.secrets/` (gitignored). En cible : HashiCorp Vault / AWS KMS / Azure Key Vault (supportés nativement par le mode `eth1`).
3. **Kafka ≠ exactly-once vers la blockchain** : l'idempotence Kafka ne couvre pas l'effet externe. → double garde :
   - *Hors chaîne* : l'adaptateur persiste `(operationId, nonce, rawTx, txHash)` **avant** diffusion, et rediffuse la même transaction signée à la reprise.
   - *Sur chaîne* : `transferWithReference(to, amount, operationId)` rejette un `operationId` déjà exécuté.
4. **Résultat inconnu ≠ échec** : un timeout RPC ne libère jamais la réservation ; seul un reçu `status=0` ou un rejet déterministe pré-diffusion le permet. Un réconciliateur rejoue la recherche du reçu.
5. **Disponible = solde indexé − montants en attente** ; la réservation ne disparaît que lorsque Ponder a indexé le bloc contenant la transaction (pas au reçu), sinon double-comptage transitoire.
6. **Supply chain** : images figées par version (digest en CI), actions GitHub épinglées par SHA, Dependabot, `npm ci` / lockfiles, pas d'installation réseau dans le sandbox d'audit.
7. **Agents** : hooks Claude Code qui interdisent la lecture de `.env`/`infra/.secrets/`, les `git push --force`, et bloquent un commit contenant un secret.
8. **Repo privé** : CodeQL/GHAS non garantis sur dépôt privé → Slither + Semgrep OSS + Gitleaks + Trivy en CI.

## 3. Variables nécessaires à la chaîne

Toutes générées par `scripts/bootstrap-env.sh` (aucune action manuelle pour le sandbox) :

| Variable | Génération |
|---|---|
| `TELA_CHAIN_ID` | Fixe (`48151`), choix local |
| `BESU_VALIDATOR_ADDRESS` + clé nœud | `besu public-key export-address` à partir d'une clé générée |
| `QBFT extraData` | `besu rlp encode --type=QBFT_EXTRA_DATA` |
| `DEPLOYER_ADDRESS`, `OPERATOR_ADDRESS`, `ALICE_ADDRESS`, `BOB_ADDRESS` | `cast wallet new` → keystores V3 chiffrés pour Web3Signer |
| `*_KEYSTORE_PASSWORD` | `openssl rand` |
| `POSTGRES_*_PASSWORD` (superuser, backend, adapter, ponder, reader) | `openssl rand` |
| `KAFKA_CLUSTER_ID` | UUID base64 aléatoire |
| `TCE_ADDRESS`, `TCD_ADDRESS`, `TIF_ADDRESS`, `SWAP_ADDRESS` | Écrites par `scripts/deploy-contracts.sh` après déploiement |

**À fournir par l'humain (non automatisable)** — voir `docs/HUMAN-ACTIONS.md`.
